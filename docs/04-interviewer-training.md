# 面试官培训手册

## 培训流程（约 2 小时）

1. **通读材料**（30 分钟）：`01-analysis.md`、`02-interview-flow.md`、`03-rubric.md`，以及自己负责方向的 3–4 道题
2. **自己先做一遍**（30 分钟）：在不看答案的情况下做 2 道题，然后对照答案。**面试官自己都没找全的题目，面试时更要严格按照提示阶梯来**
3. **互相模拟**（40 分钟）：两两一组，一人扮演候选人（包括扮演一个"用 AI 代答"的候选人），一人面试，然后交换
4. **校准**（20 分钟）：所有面试官看同一段模拟面试录像，独立打分，然后对比。同一维度相差超过 1 分的，要讨论统一

## 如何应对疑似作弊

**原则：不指责，只加大深度。**

在面试中直接指责候选人作弊，你没有证据，候选人可能确实只是紧张，而且会带来很差的体验和口碑风险。正确的做法是：

1. **切换到追问模式**：不再问"还有什么问题"，改成指向式问题、要数字、要过程
2. **使用现场变体**：改两行代码，看候选人能否基于刚才的理解快速调整
3. **使用微型手写题**：在共享编辑器中当面写 10 行代码，然后改需求
4. **如实记录**：在反馈表中写下观察到的事实（例如"每次回答前停顿约 8 秒，之后输出完整的分点列表；追问第 23 行时无法回答"），由招聘委员会决定是否安排验证面试

## 题目保密

- 这个仓库应保持为**私有仓库**，只有面试官能访问
- **候选人材料只在面试中展示**，不要提前发送，面试结束后也不要发送
- 每场面试都在反馈表中记录用了哪个变体
- 发现题目泄露时，在团队群里同步，优先换变体

## 常见问题

**问：候选人完全没接触过自动驾驶怎么办？**
答：所有题目的背景都写在题面上。考察的是工程推理，不是领域知识。如果候选人问"heading 是什么"，直接回答，不扣分。

**问：候选人用 Python，题目是 C++ 怎么办？**
答：Q02、Q05、Q09、Q12 中与 C++ 语法强相关的问题（迭代器失效、整数溢出语义等），对非 C++ 背景的候选人降低权重，重点看其余问题。也可以换成同方向的 Python 题。

**问：候选人找到了题目答案中没有列出的问题怎么办？**
答：如果确实是问题，在反馈中记录并加分，面试后提交到题库中补充答案。

**问：时间不够，题 B 没做完怎么办？**
答：在反馈中注明"未考察到的维度"，不要按 1 分处理。
