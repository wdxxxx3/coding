# M09 Flow Matching 训练 · `Flow matching` `动作头` `π0 类 VLA`

**入口（照念）**：「约定 t=0 是噪声、t=1 是数据，看看训练代码对不对。」　**时长** 6–10 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | 插值方向和约定相反 | `xt = t*x0 + (1-t)*x1` 在 t=0 时是**数据**，与"t=0 是噪声"矛盾 |
| P0 | 速度目标和插值不一致 | 实测：该插值的 d(xt)/dt = x0 − x1，而目标是 x1 − x0，符号相反。正确写法：`xt = (1-t)*x0 + t*x1`，`v = x1 - x0` |
| 加分 | 两个错误单独看都"像对的" | 只改一个地方（插值或目标），结果仍然是错的。看候选人能否用**求导检查一致性**，而不是凭记忆 |
| P2 | t 均匀采样 | π0 等工作对 t 使用非均匀采样（偏向高噪声端）。能说出 t 分布会影响什么即可 |

**追问 · 预研**：flow matching 和扩散的关系？rectified flow 为什么少步也能采样？t 的采样分布应该怎么选？
**追问 · 落地**：推理只能给 10 ms，你用几步、哪种 ODE 求解器（关联旧题库 D03：改步数时 dt 要跟着改）？动作 chunk 的平滑性怎么保证？

**锚点**：4 = 找到方向矛盾，并通过求导验证；3 = 发现不一致但说不清改哪里；2 = 提示后发现；1 = 不清楚插值路径
