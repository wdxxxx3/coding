# M05 奖励模型 · `RM` `RLHF` `偏好学习`

**入口（照念）**：「这是 Bradley-Terry 奖励模型的训练。」　**时长** 6–8 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | 右 padding 时 `[:, -1]` 取到的是 pad 位置 | 实测：长度为 3 的序列，奖励来自位置 4（pad）。应取 `attn.sum(1) - 1` 处 |
| P1 | `log(sigmoid(x))` 下溢 | 实测 x=-120 时得到 -inf，应使用 `F.logsigmoid` |
| P2 | 用 `[:B//2]` / `[B//2:]` 切分 chosen 和 rejected | 依赖 collate 的拼接顺序，shuffle 或改 collate 后静默出错。显式传两组更安全 |

**追问 · 预研**：BT 模型假设了什么？奖励的绝对值有意义吗？为什么 RM 准确率高，RL 后效果仍然可能不好（过度优化）？
**追问 · 落地**：智驾里奖励模型的标签从哪里来？标注者一致性怎么衡量？RM 上线后怎么监控它是否被策略"钻空子"？

**锚点**：4 = 找到 pad 位置 + 数值问题，能讨论过度优化；3 = 找到 pad 位置；2 = 提示后找到；1 = 不理解 BT 损失
