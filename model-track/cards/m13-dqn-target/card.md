# M13 DQN 目标 · `RL` `小模型` `决策`

**入口（照念）**：「这是一个 DQN 的更新。」　**时长** 6–8 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | 目标值和当前 Q 用同一个网络，而且没有 detach | 实测 target 带梯度：反传时也在拉动目标，训练不稳定。应使用目标网络并在 `no_grad` 下计算 |
| P0 | 超时也当成 done | 超时是外部截断，应该 bootstrap；只有碰撞等真正终止才乘 0（关联旧题库 R02） |
| P2 | `max` 导致高估 | Double DQN：用在线网络选动作，用目标网络评估 |

**追问 · 预研**：为什么需要目标网络？离线 RL 中为什么高估问题更严重（CQL 等方法的动机）？
**追问 · 落地**：奖励怎么设计（安全、舒适、效率）？在仿真里训练好的策略，迁移到真车前要做哪些验证？

**锚点**：4 = 两个 P0 + Double DQN；3 = 两个 P0；2 = 一个；1 = 不理解 TD 目标
