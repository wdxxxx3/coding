# M01 SFT 损失 · `SFT` `LLM` `VLM` `VLA`（通用兜底卡）

**入口（照念）**：「这是一段 SFT 的 loss，你觉得能直接用吗？」　**时长** 6–10 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | 没有错位 | causal LM 在位置 t 预测 t+1。应为 `logits[:, :-1]` 对 `labels[:, 1:]`。不错位时模型在位置 t 已经能看到 token t，loss 会非常低但学到的是复制 |
| P0 | prompt 没有屏蔽 | 题面要求只训 response，prompt 部分也算了 loss（是否屏蔽可讨论，但要能说出差别） |
| P0 | `pad_id == eos_id` | `labels[ids == pad] = -100` 把**真正的 EOS 也屏蔽了**（实测：EOS 不再被监督）→ 模型学不会停止，生成停不下来 |
| P2 | `cross_entropy` 默认按 token 平均 | 和"按样本平均"是不同目标；梯度累积时分母要跨 microbatch（关联旧题库 D01） |

**追问 · 预研**：packing 多条样本时 loss 和 mask 怎么处理（关联 R03）？只训 response 和全训，对指令跟随有什么影响？
**追问 · 落地**：线上发现"生成停不下来"或"重复输出"，你会先查什么？（数据里 EOS 的位置、tokenizer 配置、本卡的第 3 个问题）

**锚点**：4 = 三个 P0 全部独立找到，并说出"停不下来"的现象；3 = 找到错位 + 一个其他问题；2 = 只找到一个；1 = 说不清 labels 怎么对齐
