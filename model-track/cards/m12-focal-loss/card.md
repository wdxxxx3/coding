# M12 Focal loss · `感知` `检测` `小模型`

**入口（照念）**：「这是检测头的 focal loss。」　**时长** 6–8 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | `log(sigmoid)` 数值不稳定 | 实测：logit=100、target=1（预测完全正确）时 loss = **NaN**（`0 * log(0)`）。应使用 `binary_cross_entropy_with_logits` |
| P0 | `num_pos = 0` 时除零 | 高速空旷路段常有帧内没有目标，实测得到 inf。用 `max(num_pos, 1)` 或跨卡同步后的正样本数 |
| P1 | alpha 没有区分正负样本 | 原版是 α_t：正样本 α，负样本 1−α。这里所有样本都乘 α，等价于只缩放了总 loss |

**追问 · 预研**：γ 的作用？focal loss 和难例挖掘的关系？类别极度不平衡时（施工锥桶、动物）还有什么办法？
**追问 · 落地**：多卡训练时 num_pos 怎么归一化（关联旧题库 D01）？量化到 int8 部署后 sigmoid 输出的置信度校准会怎么变？

**锚点**：4 = 三个问题都找到，并给出数值稳定的写法；3 = 找到两个 P0；2 = 找到一个；1 = 不了解 focal loss
