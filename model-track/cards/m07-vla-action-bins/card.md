# M07 VLA 动作离散化 · `VLA` `动作 token` `落地`

**入口（照念）**：「这是 VLA 里把连续动作变成 token 的代码。」　**时长** 8–12 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | 等于 hi 时得到 256，越界 | 实测 `tokenize(hi) = 256`，有效范围是 0–255。需要 clamp；超出 [lo, hi] 的动作也要 clamp |
| P1 | 反离散化返回桶的左边界 | 系统性偏差半个桶宽，应 `(tok + 0.5) / n_bins`。实测 0.03 m/s² 还原为 0 |
| P1 | 用训练集 min/max 定范围 | 一个异常值就会撑大范围、降低分辨率。常用 1%/99% 分位数并截断 |
| 落地 | 曲率量化误差 | ±0.2 1/m 分 256 桶，半桶 ≈ 0.00078 1/m；30 m/s 时横向加速度误差 ≈ v²κ = **0.70 m/s²**（已计算）。高速下这个误差不可接受 → 需要按速度分段、非均匀分桶，或改用连续动作头（flow/diffusion） |

**追问 · 预研**：离散动作 token vs flow matching 动作头（π0 类）的取舍？FAST 这类基于频域压缩的动作 tokenizer 解决了什么问题？
**追问 · 落地**：这 256 个 token 占用词表的哪部分（覆盖低频 token？）？动作 chunk 的长度和控制频率怎么匹配（关联旧题库 R10）？

**锚点**：4 = 越界 + 半桶偏差 + 能自己算出高速量化误差；3 = 越界 + 一个 P1；2 = 只看到越界；1 = 不理解离散化
