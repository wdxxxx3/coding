# M08 轨迹扩散训练 + CFG · `Diffusion` `生成式规划`

**入口（照念）**：「这是一个预测噪声的轨迹扩散模型，训练和推理各一段。」　**时长** 8–12 分钟

| 级别 | 问题 | 说明 |
|---|---|---|
| P0 | `alpha_bar[t]` 形状 [B] 和 x0 [B, 16] 广播 | [B] 会对齐到**最后一维**。实测：B=8 时报错，**B=16 时不报错但结果是错的**（每个样本用了别的样本的噪声水平）。应 `alpha_bar[t][:, None]` |
| P0 | 目标写成 x0，但模型设计为预测 eps | 训练和推理参数化不一致，采样公式全错。目标应为 `noise`（或者统一改成 x0 参数化） |
| P0 | 训练时从来没有丢弃条件 | CFG 需要模型学过无条件分布（训练时以 10%–20% 概率把 cond 换成 null）。否则 `null_cond` 的输出是未定义的 |
| P2 | 推理时每步调用两次 model | 能想到把条件和无条件拼成一个 batch，加分 |

**追问 · 预研**：预测 eps、x0、v 三种参数化各有什么优缺点？guidance 系数 w 变大，轨迹的多样性和"合规性"怎么变化？
**追问 · 落地**：扩散步数和车上延迟预算怎么平衡（DDIM、蒸馏、一致性模型）？多模态轨迹采样后怎么选出一条执行（打分器、规则过滤）？

**锚点**：4 = 三个 P0 全部找到，能解释 B=16 不报错的原因；3 = 找到两个；2 = 只找到一个；1 = 说不清前向加噪公式
