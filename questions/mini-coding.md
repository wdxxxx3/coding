# 微型手写题（可选，≤ 10 分钟）

**用途**：确认候选人"真的能写代码"，作为底线检查，不作为主要考察。在主题结束后剩余时间里使用，或在怀疑候选人代答时用来验证。

**规则**：
- 在共享编辑器中**当面写**，不超过 20 行，不要求能运行
- 写完之后**立刻改需求**（现场变体），看他能不能在自己的代码上快速修改，这一步比第一版更重要
- 只评"能不能写、写得对不对、改得快不快"，不评代码风格

| # | 题目 | 关键点 | 现场变体 |
|---|---|---|---|
| M1 | `normalize_angle(a)`：把任意角度归一化到 [-π, π) | Python 的 `%` 与 C++ 的 `fmod` 对负数的处理不同；`while` 循环遇到大数或 NaN 会出问题 | 「改成 C++」「输入是 1e10 呢？」 |
| M2 | `interp(ts, vs, t)`：已知按时间排序的序列，求 t 时刻的线性插值 | 二分查找；越界处理；时间戳重复 | 「如果 vs 是角度呢？」（结合 Q01/Q05） |
| M3 | 两个区间 [a1, a2]、[b1, b2] 的 IoU | 不相交时交集为 0；分母为 0 | 「扩展到 2D 轴对齐框」 |
| M4 | 滑动窗口中位数滤波（窗口为 k） | 边界；复杂度 | 「k 很大时怎么优化？」 |
| M5 | 点到线段的最近距离 | 投影参数 t 要截断到 [0, 1] | 「扩展到折线；返回左右符号」（结合 Q10） |
| M6 | 环形缓冲区 push / get_latest(n) | 下标取模；满和空的判断 | 「多线程一写一读怎么做？」 |

## 评分
- **通过**：10 分钟内写出基本正确的版本，并能在 2–3 分钟内完成变体
- **存疑**：第一版写得很快很完整，但改需求时明显卡住或者需要重写 → 在反馈中如实记录，作为可信度标记（见 `docs/04-interviewer-training.md`）
