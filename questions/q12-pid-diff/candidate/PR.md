# [SpeedPid] 修复满载爬坡时速度跟不上的问题

## 背景
重卡满载（49 t）在长上坡上，实际车速持续低于目标速度 3~5 km/h，用户反馈"爬坡没劲"。
`Compute()` 由控制线程调用，`dt` 为本次与上次控制消息时间戳之差。输出 [-1, 1]，正为油门，负为制动。

## 改动
1. 去掉积分限幅，让积分项能充分累积，解决爬坡稳态误差。
2. 微分项改为对误差求导，响应更快。
3. 去掉冗余的 `dt <= 0` 判断（控制周期固定 20 ms）。
4. 变量改名、加 const，提升可读性。

## 测试
仿真中满载 3% 坡道稳态误差从 4 km/h 降到 0.3 km/h。
